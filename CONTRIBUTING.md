# Contributing to fa-redact

Thank you for your interest in contributing to `fa-redact`.

`fa-redact` is a privacy-first Persian PII detection and de-identification toolkit, with a particular focus on healthcare, clinical NLP, and sensitive-data workflows.

Contributions are welcome, including bug fixes, new detectors, Persian-language improvements, tests, documentation, performance improvements, and carefully scoped architectural changes.

Before contributing, please read this document carefully.

---

## 1. Contribution Workflow

`fa-redact` uses a **fork → branch → pull request** workflow.

You do not need write access to the main repository.

### Step 1 — Fork the repository

Fork:

https://github.com/mehdimt1980/fa-redact

to your own GitHub account.

### Step 2 — Clone your fork

Replace `<your-username>` with your GitHub username:

```bash
git clone https://github.com/<your-username>/fa-redact.git
cd fa-redact
